## Introduction

This datasheet covers the design, implementation, and component selection for the MQTT subsystem. My subsystem is responsible for implementing a two-way wireless communication between my board (via an ESP32 microcontroller) and an external server (MQTT Explorer) via MQTT network protocol.

### Project Summary

Our team is building an autonomous rover that uses a daisy-chained UART communication network to connect multiple subsystems together. Each team member was responsible for one subsystem. My board is in the middle of the daisy chain and passes down some commands to the next board in the chain, and takes some data and sends it to the MQTT Explorer server.

Link to my team report: [Team Report](https://egr314-s-2026-30.github.io/EGR314-S-2026-305.github.io/)

### My Contribution

I was responsible for designing and implementing an MQTT subsystem. This mainly includes:
* Designing a functional two-way communication system between different boards using UART.
* Designing a functional two-way wireless communication system between my board and the internet using MQTT.
